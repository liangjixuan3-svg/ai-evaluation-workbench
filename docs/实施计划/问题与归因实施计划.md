# 问题与归因实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建成使用真实评测数据的问题簇工作台，支持查看代表样本、按需调用当前模型生成归因建议、人工确认并创建改进任务。

**Architecture:** 后端新增独立 `issues` 查询模块，组合已有问题簇、评测结果、告警、归因建议和任务数据，不新增数据库表。操作继续复用 `analysis` 和 `remediation` 领域服务；前端新增独立 API 模块和“左侧问题列表、右侧处理详情”页面。

**Tech Stack:** FastAPI、SQLAlchemy 2、Pydantic、MySQL/SQLite 测试、React 19、TypeScript、Vitest、CSS。

## 全局约束

- 只展示真实数据库数据，不增加前端演示问题。
- 归因按需触发，不在评测完成后自动追加模型调用。
- 归因接口使用后端当前配置的真实模型；密钥不返回前端。
- 对话在返回页面前执行现有脱敏逻辑。
- 人工确认和改进任务必须可追溯且保持幂等。
- 不新增数据库表，不开发 QA 审核页面和复杂图表。
- 产品和实施说明使用中文名称并放在现有固定目录。
