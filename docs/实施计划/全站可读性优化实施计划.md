# 全站可读性优化实施计划

> **执行要求：** 修改后必须运行前端自动化测试和生产构建，不启动用户的开发服务。

**目标：** 统一提高工作台小字号内容的可读性，同时保持现有布局与视觉语言。

**实现方式：** 在 `frontend/src/styles/theme.css` 中建立集中式字号覆盖规则。按正文、辅助信息、交互控件和移动导航四类调整，避免逐个 React 组件散改。

**技术栈：** CSS、React 19、Vite、Vitest。

## 全局约束

- 正文不低于 `13px`，辅助信息不低于 `11px`。
- 不修改业务接口、数据库或组件数据流。
- 不新增依赖。
- 不启动前后端服务。
