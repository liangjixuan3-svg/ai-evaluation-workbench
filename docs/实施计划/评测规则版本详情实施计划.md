# 评测规则版本详情实施计划

> **执行要求：** 使用测试驱动方式逐项实施，每项完成后独立验证。

**目标：** 支持用户从评测运行页打开本次运行绑定的完整公司质量标准只读详情。

**架构：** 后端通过版本 ID 返回经过严格合约校验的已发布版本；运行详情返回绑定版本 ID。前端新增独立只读路由，运行页只负责跳转，规则展示由专用页面负责。

**技术栈：** FastAPI、SQLAlchemy、Pydantic、React、TypeScript、Vitest。

## 全局约束

- 只展示指定历史版本，不回退或跳转到最新版本。
- 草稿版本禁止通过只读接口访问。
- 页面文案和说明文件使用中文。
- 不增加编辑、复制和发布操作。
