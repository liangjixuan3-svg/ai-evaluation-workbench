# 01 今日工作台需求

## 1. 模块目标

让质量负责人快速判断当前质量状态、待处理事项和第一优先任务，并能直接进入下一处理页面。

## 2. 使用角色与场景

- 角色：AI 产品经理、客服运营负责人、质检人员。
- 场景：每天开始质量运营、检查任务积压、跟踪改进进度。

## 3. 前置条件

- 系统已经产生评测结果、告警或人工任务。
- 无真实业务数据时允许展示明确标记的演示数据。

## 4. 核心功能需求

1. 展示当前整体通过率和相对变化。
2. 展示新告警、待确认归因、QA 待审核和待复测数量。
3. 统一展示告警和人工任务组成的优先处理队列。
4. 每个任务必须提供唯一、明确的下一步入口。
5. 展示改进闭环各阶段数量和最近操作动态。

## 5. 关键业务规则

- 优先任务按优先级、影响量和等待时间排序。
- 首页只汇总状态，不在首页完成归因、审核或复测。
- 演示数据必须与真实数据明显区分。
- 首页数字应与各业务模块中的真实状态一致。

## 6. 页面状态与异常

- 加载中显示明确提示。
- 没有任务时展示空状态。
- 接口不可用时不得把演示数据冒充真实数据。
- 任务失效时目标页面应提供返回入口和中文错误说明。

## 7. 验收标准

1. 用户能在 30 秒内判断质量状态和第一优先事项。
2. 每个任务都能进入正确处理模块。
3. 待办数量与各模块数据一致。
4. 无真实数据时不会展示误导性的线上结论。

## 8. 暂不包含

- 自定义看板和复杂趋势分析。
- 首页直接编辑业务记录。
- 多人任务分配和个人工作量统计。
