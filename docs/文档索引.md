# 文档索引

项目说明文件统一使用中文名称，并固定放在以下目录：

- `需求文档/`：放产品总需求和按页面模块划分的简明功能需求。
- `产品设计/`：放详细产品方案、页面流程和数据设计说明。
- `实施计划/`：放开发步骤、任务拆分和验收计划。

文件名直接描述主题，不添加日期、英文流程名或工具名称。修改同一主题时更新原文件；只有内容代表独立产品能力时才新建文件。

安装、服务启停和日常操作请查看仓库根目录的[使用说明](../使用说明.md)；其中包含“评测校准”的人工复核步骤。
