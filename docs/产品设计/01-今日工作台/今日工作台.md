# 今日工作台

## 1. 模块目标

今日工作台是产品首页，用一页回答三个问题：今天质量是否异常、最应该先处理什么、每个问题下一步去哪里处理。它不是单纯的数据看板，而是整个质量运营闭环的任务入口。

## 2. 页面入口

左侧导航“01 今日工作台”，路由为 `/`。

## 3. 页面结构

### 3.1 今日质量概况

顶部展示整体通过率和相对变化，让用户先判断当前质量水位。无真实数据时页面明确显示演示数据，不把演示指标伪装成线上结果。

### 3.2 待办数量

页面汇总四类待办：

- 新告警。
- 待确认归因。
- QA 待审核。
- 待复测。

数量用于判断积压，不替代具体任务处理。

### 3.3 优先处理队列

告警和人工任务统一进入优先队列，按优先级、影响对话数和创建时间排序。每张卡片只提供一个明确的下一步，例如“查看样本并确认归因”“审核 QA 草稿”或“查看复测进度”。

### 3.4 改进闭环与最近动态

闭环区展示自动评测、问题归因、QA 发布和确认恢复的阶段数量；最近动态展示关键人工操作和系统事件，帮助团队了解处理进展并保留审计线索。

## 4. 数据口径

- 今日通过率来自正式评测结果。
- 新告警包含尚未恢复的活动告警。
- 待确认归因来自开放的归因任务。
- QA 待审核来自待审核草稿。
- 待复测来自排队中或执行中的复测任务。
- 最近动态来自审计事件，最近评测来自评测运行记录。

## 5. 使用方式

1. 每天先打开今日工作台判断整体质量。
2. 从“优先处理”第一项开始，点击卡片进入对应模块。
3. 完成归因、QA 审核或复测后返回首页，确认待办数量和状态已更新。
4. 数据采集和发起评测属于主动操作，通过左侧对应模块进入，不混入人工待办队列。

## 6. 异常与空状态

- 接口加载期间显示明确的整理状态。
- 接口不可用时展示演示数据并标记“演示数据”。
- 没有任务时显示清晰空状态，不制造虚假告警。
- 卡片指向的业务记录失效时，目标页面负责显示可恢复的错误信息。

## 7. 验收标准

1. 用户能在 30 秒内判断当前质量状态和第一优先事项。
2. 每个任务只有一个明确下一步，且能进入正确模块。
3. 首页汇总与各业务模块状态保持一致。
4. 演示数据与真实数据有明显区分。
