# 评测 Prompt 版本管理

## 1. 目标

让运营人员无需修改代码即可维护大模型评测指令，并让每次评测固定记录实际使用的 Prompt 版本。公司质量标准负责“评什么”，评测 Prompt 负责“模型如何执行和解释”。

首版只开放评测指令文本。五个评分维度、JSON 输出字段、证据引用要求和安全校验由系统固定，不能在页面修改。

## 2. 页面入口

“评测规则”模块增加两个页签：

- 公司质量标准：保留现有 Word/PDF 规则配置能力。
- 评测 Prompt：管理 `customer-support-judge` 的版本。

Prompt 页面左侧展示版本列表和状态，右侧展示只读版本或草稿编辑器。发起评测页面增加“评测 Prompt”选择框，默认选中当前启用版本，也允许选择历史已发布版本用于对比评测。

## 3. 版本流程

1. 系统自动提供内置 V1，首次打开页面或发起评测时保证其存在。
2. 已发布版本不可修改。
3. 用户点击“复制为新版本”，系统按当前最高版本号创建一个草稿。
4. 草稿可以反复保存；首版同一时间只保留一个草稿。
5. 发布草稿后，该版本成为默认启用版本，旧版本保留并可继续被历史运行追溯或手动选择。
6. 已被评测运行引用的版本永不删除。

版本状态使用 `published_at` 判断：为空是草稿，非空是已发布。`active` 只表示当前默认版本，不再承担草稿含义。

## 4. Prompt 边界

模型收到的 system message 由两段组成：

```text
可版本化评测指令
+
系统固定输出协议
```

可版本化部分允许描述评测角色、判断原则、解释风格和公司规则使用方法。固定部分强制模型返回五维分数、理由、原文证据、置信度及严重错误标记，并继续经过现有后端结构校验和证据校验。

公司质量标准仍作为结构化 `company_quality_standard` 输入发送给模型，不写入 Prompt 文本，避免每次公司制度变化都产生一个 Prompt 版本。

## 5. 数据与接口

在现有 `prompt_versions` 表增加 `published_at`：

- 现有内置 Prompt 迁移为已发布版本。
- 新草稿 `active=false`、`published_at=null`。
- 发布时设置 `published_at`，启用当前版本并停用同名称的其他版本。

提供以下接口：

- `GET /api/evaluation-prompts`：列出全部版本，并保证内置 V1 存在。
- `POST /api/evaluation-prompts/drafts`：复制指定已发布版本生成新草稿。
- `PUT /api/evaluation-prompts/{id}`：保存草稿内容。
- `POST /api/evaluation-prompts/{id}/publish`：发布并锁定草稿。

发起评测参数增加 `prompt_version_id`。后端只接受已发布版本，并将其写入 `evaluation_runs.prompt_version_id`。运行去重键同时包含 Prompt 版本，避免不同 Prompt 错误复用同一次运行。

## 6. 页面行为

已发布版本显示版本号、发布时间、是否当前默认及完整 Prompt，只提供“复制为新版本”。草稿显示文本编辑区、“保存草稿”和“发布版本”。空内容、超长内容或与已发布版本完全相同的内容不能发布，并返回中文错误。

发起评测页显示“Prompt 名称 · V版本号 · 当前默认”标签。运行详情显示实际 Prompt 版本，和公司规则版本一起形成完整追溯信息。

## 7. 异常处理

- 数据库中存在旧 Prompt 但没有 `published_at` 时，迁移将其标记为已发布，避免历史运行失去引用。
- 请求草稿参与评测时返回 422，不自动回退到默认版本。
- 模型返回不符合固定输出协议的结果时，继续走现有单条重试和人工处理流程。
- 发布冲突使用事务处理，保证同一个 Prompt 名称只有一个默认启用版本。

## 8. MVP 不包含

- 修改模型参数、五维字段或 JSON 输出结构。
- 在线单条试跑、A/B 实验和自动效果对比。
- Prompt 自动优化或自动发布。
- 删除已发布版本。

## 9. 验收标准

1. 用户可以查看内置 V1、复制新建草稿、保存并发布 V2。
2. 已发布版本不能修改，发布后 V2 成为默认，V1 仍可查看和选择。
3. 发起评测必须选择已发布 Prompt，运行记录保存所选版本。
4. 模型请求实际使用所选版本内容，而不是代码中的固定评测指令。
5. 用户无法通过页面修改固定输出协议，现有结构与证据校验继续生效。
6. 旧评测运行仍能追溯原 Prompt 版本。
