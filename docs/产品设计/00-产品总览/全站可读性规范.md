# 全站可读性规范

## 目标

解决工作台中大量 `8–10px` 文字难以阅读的问题，在不改变现有视觉风格和页面结构的前提下，提高桌面端与移动端的信息可读性。

## 字号层级

- 正文、对话内容、评测理由：不低于 `13px`，行高不低于 `1.6`。
- 表单标签、按钮、状态、列表信息：`12–14px`。
- 辅助说明、时间、模型名称等次要信息：不低于 `11px`。
- 主导航：桌面端 `15px`，移动端 `10px`。
- 页面大标题、数据数字和品牌字号保持现有比例，不盲目放大。

## 实现方式

在全局主题文件末尾增加集中式可读性覆盖层。覆盖层按信息角色统一字号，并适当增加表单和按钮高度；组件结构、颜色、数据逻辑和响应式布局不变。

## 验收标准

- 业务正文不再使用小于 `13px` 的字号。
- 辅助信息不再使用小于 `11px` 的字号，装饰性序号除外。
- 输入框、选择框和按钮文字达到 `13px`，控件高度不低于 `44px`。
- 桌面端不出现主要卡片文字溢出，移动端导航仍可完整展示七个入口。
- 前端测试和生产构建通过。
