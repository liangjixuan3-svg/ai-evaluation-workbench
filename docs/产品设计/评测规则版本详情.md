# 评测规则版本详情

## 目标

让用户从评测运行页查看本次运行实际使用的完整公司质量标准，而不只看到标准名称和版本号。

## 页面流程

1. 评测运行页在标准名称和版本号旁展示“查看完整规则”入口。
2. 入口携带本次运行绑定的 `quality_standard_version_id`，打开只读版本详情页。
3. 详情页展示标准名称、版本号、发布时间、通过阈值、五维权重、评分档位、通用规则和场景规则。
4. 每条规则展示标题、要求、影响维度、规则效果、原文引用和原文位置。
5. 详情页只读取指定历史版本，不自动跳转到最新版本，也不提供编辑或发布操作。

## 接口

- 运行详情增加 `quality_standard.version_id`。
- 新增 `GET /api/quality-standards/versions/{version_id}`，只返回已发布版本。
- 版本不存在返回 404；版本未发布返回 409。

## 前端路由

- 新增 `/rules/versions/:versionId`。
- 运行详情页链接到该路由。
- 页面沿用现有纸张式视觉体系，规则较多时按“通用规则”和“场景规则”分组纵向阅读。

## 验收标准

- 从历史运行打开的始终是该运行绑定的版本。
- 阈值、权重和规则内容与数据库中的不可变版本快照一致。
- 草稿版本不能通过该只读入口访问。
- 桌面端和移动端均能阅读完整规则。
